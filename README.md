# CinemaDoc Landing

Статический лендинг CinemaDoc для презентации продукта, тарифов, калькулятора и формы заявки.

## Структура

- `index.html` — общий файл лендинга.
- `styles/` — стили, разбитые по экранам.
- `sections/` — HTML-блоки экранов для удобного редактирования.
- `scripts/split-sections.mjs` — утилита для повторной нарезки секций из общего файла.

## Публикация

Лендинг опубликован на Vercel: https://cinemadoc-landing.vercel.app
